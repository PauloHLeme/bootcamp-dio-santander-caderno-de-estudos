Bem-vindo(a) ao meu caderno de estudos! Este repositório foi criado para documentar meu progresso e aprendizados durante o **Bootcamp de Ciência de Dados da DIO em parceria com o Santander**.

Decidi torná-lo público para que possa servir de inspiração e material de consulta para outros estudantes. Sinta-se à vontade para explorar os resumos, sugerir melhorias ou até mesmo criar seu próprio caderno a partir deste modelo.
