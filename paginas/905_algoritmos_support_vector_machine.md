# Algoritmos SVM - Support Vector Machine

O Algoritmo SVM, ou Máquina de Vetor de Suporte, funciona de maneira muito similar a uma RNA, mas ele é especializado em categorizar dados.

Para isso, ele conta com treinamento assistido, ou seja, toda a base de dados que damos para ele treinar já está catalogada, e ele vai aprender categorizando essa base de dados em um plano cartesiano, ou uma área, e então atribuir valores que determinam cada dado dentro deste plano.

Com isso definido, a SVM passa um hipervetor separando os dados em dois ou mais campos claramente divididos, e preferencialmente com uma zona livre entre o vetor e os dados, o que trás uma maior garantia de que os dados serão catalogados corretamente.

## Outliers

As SVM são excelentes para classificar dados bem distintos entre si, mas existem alguns casos onde um elemento acaba sendo confuso e se misturando dentro da outra classificação.

As boas SVMs são capazes de lidar com estes Outliers, pois elas sabem identificar as regiões que estão com tais elementos e retirá-los do modelo, ignorando aqueles dados.
