# Linguagens de Programação para Machine Learning

## Linguagens mais Utilizadas

Temos bibliotecas para Machine Learning na maioria das linguagens de programação, porém algumas se destacam nesta área.

Temos principalmente _R_, _SciLab_ e _Python_.

R e Scilab são altamente utilizadas no meio acadêmico, e Python é muito utilizada no meio comercial.

Atualmente, os maiores grupos de pesquisa na área de ML estão programando em Python, com as principais bibliotecas de IA sendo contruídas e desenvolvidas para esta linguagem.

## Paradigmas de Programação

Um paradigma de programação determina a visão de como será feita a estruturação, a execução, a abordagem e a sintaxe do programa.

É a forma que iremos abordar o problema, e como será feita a solução dele.

### Lógico

É uma linguagem que, como o nome diz, é voltada para a lógica de resolução de situações semelhantes a forma como o próprio computador soluciona os problemas, através de lógica matemática.

É um paradigma bem utilizado para processamentos naturais, pois tentamos aproximar a lógica computacional e a linguagem humana.

Linguagens como _Prolog_ se utilizam muito deste paradigma.

### Funcional

É um paradigma que trabalha voltado para funções. Funções são resoluções matemáticas que levam em consideração diversos fatores, e retorna uma solução baseado no processo de todos os cálculos envolvidos nessas funções.

Desta forma, temos reutilização de funções quando necessário, bem como valores bem definidos que são passados para cada uma destas funções.

É altamente utilizada em cálculos probabilísticos.

_Python_, _R_ e _JavaScript_ são muito utilizados com o paradigma funcional.

### Imperativo

É relacionado com a comunicação real que temos com o mundo. Nela, nós colocamos o passo a passo de forma semelhante a resolver um problema do dia a dia, com uma série de ações, enunciados ou comandos.

Linguagens como _C_ e _Assembly_ são muito utilizadas neste paradigma.

### Orientado a Objetos

Neste paradigma, o problema é fracionado em diversas partes, modulando todas as partes do código em objetos diferentes, que podem ser reutilizados em momentos posteriores.

É um paradigma mais robusto, com uma grande abstração e reaproveitamento de objetos ainda maior que na programação funcional, pois abstraímos ao máximo os compartimentos que geram os objetos.

É baseado nos pricípios de Polimorfismo, Herança, Encapsulamento e Abstração.

_Java_ é o sinônimo de POO (Programação Orientada a Objetos), mas é um paradigma que pode ser utilizado em outras linguagens, como o _Python_, por exemplo.
