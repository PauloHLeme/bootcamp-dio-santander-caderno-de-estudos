# Classificação de Problemas: Explorando Datasets

## O que São Datasets

Datasets são conjuntos de dados. Em sistemas de Redes Neurais, nós utilizamos principalmente datasets para treinar os modelos. Para isso, os Datasets utilizados em SVM são conjuntos muito bem estabelecidos com vários dados dos mais variados tipos que representem da forma mais completa possível a área de cobertura do problema.

### Variedade de Dados

Um dataset contendo 5000 fotos de Pinscher é excelente para um sistema que queira identificar o que é um Pinscher, mas é muito fraco para um sistema que vai tentar definir o que é um cachorro, por exemplo.


### Posições e Ambiente

Ainda usando o reconhecimento de cachorros como exemplo, se só tivermos exemplos de cachorros deitados de lado, vai ser mais difícil reconhecer um cachorro de pé, de costas. Dessa forma, posições variadas também são muito relevantes para datasets.

### Amostragem

Para treinamento com base nos dados, quanto mais exemplos tivermos no dataset, melhor. 

Uma amostragem de 10 cães pode ser muito pouco para que o sistema consiga identificar de forma relevante. Nesses casos, datasets com 100 a 200 exemplos de cachorros vai ser muito mais válido.

Podemos também colocarmos milhares de fotos de cães, mas temos que levar em consideração que isso vai custar tempo, capacidade computacional e dinheiro. É bom, é válido, mas temos que avaliar se é necessário.
